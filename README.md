# COVID-19 Data Visualization Dashboard

## About This Project
This project is about understanding COVID-19 data using Power BI.

The dashboard shows information about confirmed cases, recovered cases, and deaths.

## What This Dashboard Shows
- Confirmed COVID-19 cases
- Recovered cases
- Deaths
- Year-wise data
- State and Union Territory data
- Data comparison through charts

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Project Goal
To make COVID-19 data easy to understand through charts and visuals.
